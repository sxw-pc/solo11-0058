# 离线与合规边界

## 运行期网络

- 程序不包含任何外部 HTTP 客户端调用、下载逻辑、遥测或自动更新；
- 不访问真实数据源、数据库、对象存储或外部 API；
- 测试使用随机空闲端口的本机回环 HTTP 服务，并禁用环境代理后访问 `127.0.0.1` / `::1`；
- 报告 HTML 与查看器 HTML 全部内联 CSS，无 `<script>`、无 CDN、无外部字体/图片/链接；
- `serve` 只接受 `127.0.0.1` 或 `::1`，传入其他 host 会抛出 `ValueError`；不提供公网绑定、反向代理或 TLS 管理。

## 只读 Web 边界

查看器只提供：

- `GET /healthz`；
- `GET /`：运行列表；
- `GET /run/<run_id>`：查询计划、文件决定、风险与统计检查；
- `GET /favicon.ico` 返回空。

`POST`、`PUT`、`PATCH`、`DELETE`、`HEAD`、`OPTIONS` 一律返回 `405`，`Allow: GET`。没有写入、删除、配置变更、上传或执行接口。SQLite 连接使用 `query_only = ON` 和只读查询辅助函数，HTTP 层无法修改台账。

## 数据与标识

- 所有 fixture、查询、状态文本、站点号、设备号均为合成数据；
- 使用 `demo-*`、`example.invalid` 语义或本地回环地址说明，不包含真实公司名、真实域名、真实 IP 目标、真实邮箱、真实证书、真实密钥或令牌；
- manifest 中只有本地相对路径、虚构数值和 sha256 校验值；
- SQLite 只保存配置路径、湖根路径、manifest 指纹、报告、计划、风险和统计检查，不含凭据。

## 路径与输入安全

- manifest 路径必须是相对 POSIX 路径，拒绝绝对路径、反斜杠、`..` 越界和 symlink 逃逸；
- 分区值先按声明类型 coercion，失败时记录 `TYPE_DRIFT` 并保留原值作为证据；
- 谓词解析使用自研 lexer/parser，不使用 `eval` / `exec`，不支持函数、子查询、LIKE、正则或 SQL 片段；
- CSV/JSONL 只读本地文件；JSONL 非对象行、非法 JSON 或读取失败产生稳定审计错误。

## 明确不实现

不执行真实 SQL，不连接数据库/对象存储；不解析 Parquet/ORC/Avro footer；不做表维护、小文件合并、孤儿文件清理、快照过期；不做版本账本、时间旅行、回填审计；不做冷热分层、迁移编排、生命周期执行；不做字段血缘、关联发现、指标校准、抽样、脱敏；不做调度器、分布式执行、任务队列；不做用户权限、登录、RBAC、写入后台；不做真实数据采集、爬虫、RPA；不提供公网部署、反向代理、TLS 证书管理。

## 交付产物

仓库不包含虚拟环境、数据库文件、二进制构建产物、缓存目录或下载依赖。`runtime/` 为运行时目录，可由 `demo` / `audit` 重建；交付时保持为空或不存在。提交的 fixture、配置、golden 和报告 schema 全部为文本。
